# better-feel-camera
I made the camera feel so much better in godot

In this Project, I've build a reusable camera controller in Godot with a few simple features that can make a big difference:
- Smooth camera follow with a deadzone
- Look-ahead based on player movement
- Vertical camera look
- Trauma-based camera shake
- Debug visualization and customizable settings

We'll build everything into one Camera2D script, so you can reuse it in your own projects.
